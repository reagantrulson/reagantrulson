# Hi, my name is Reagan Trulson 🪐

B.S. Applied Mathematics student at Utah State University (4.0 GPA, graduating in 3 year timeline - Spring 2027),
researching nonlinear observability theory and its applications to astrodynamics and orbit
determination under Dr. Erin Beckman and Dr. Jackson Kulik.

Working at the intersection of numerical analysis, probability, and orbital mechanics — building
Python simulations to test where classical mathematical tools break down for nonlinear systems,
and experimenting with new statistical approaches (partial distance correlation) to pick up where they
fall short.

---

### Current Research

Investigating how much a satellite's future state can be reconstructed from partial, noisy
measurements — and where linear observability theory's classical assumptions fail once the
underlying dynamics are nonlinear. Beginning work with solutions for orbital uncertainty
propagation — investigating how these results connect to and extend the observability
framework above.

- **[Undergrad-Research-Trulson](https://github.com/reagantrulson/Undergrad-Research-Trulson)** —
  Full observability pipeline for the two-satellite liaison problem (orbit simulation, State
  Transition Matrix, observability Gramian, SVD-based rank analysis), plus an application of
  partial distance correlation that catches false-positive observability results a classical
  linear test would miss.
